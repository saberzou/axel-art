## What I Learned from asciiart.website

**The Master Resource:**
- Christopher Johnson's collection: **6,527 artworks** (since 1994!)
- **Joan Stark (jgs)** is THE legend - her work is everywhere
- **103 rabbits** in their collection alone!

**Key Lessons:**

### 1. **Simplicity Wins**
The best ASCII art is often the SMALLEST:
```
(\/)
( •.•)
/ > 🥕
```
This 3-line rabbit beats my 10-line elephant any day.

### 2. **Fixed-Width Font is EVERYTHING**
- ASCII art ONLY works in monospace fonts
- Every character must occupy the same width
- This is why it survives across decades

### 3. **Style Categories I Found:**
- **Ultra-minimal:** 3-5 lines (owl, penguin, tiny rabbits)
- **Geometric:** Clean shapes, symmetrical (fox, bat)
- **Detailed:** 15+ lines (complex rabbits, elephants)
- **Organic:** Flowing curves (whale, snake, octopus)

### 4. **What Makes Art "Readable":**
- **Eyes** are crucial - `O.O`, `o o`, `@ @` instantly make it alive
- **Symmetry** helps recognition
- **Negative space** matters as much as characters
- **Less is more** - every extra line should earn its place

## Principles Going Forward

1. **Start minimal, add only if needed**
2. **Test readability: if you can't tell what it is in 2 seconds, simplify**
3. **Eyes + basic shape = recognizable**
4. **Reference the masters at asciiart.website**
5. **Keep file sizes under 250 bytes for minimal style**

## Connection to NORMIES Project

Both NORMIES and ASCII art share the same core principle:
> **Minimum visual information, maximum recognizability**

- NORMIES: AI → 40x40 pixelation → 5-20 byte SVGs
- ASCII art: Concept → character placement → ~200 byte .txt files

Same philosophy, different medium! 🐯✨
